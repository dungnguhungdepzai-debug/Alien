# Alien Client — Lightning GUI source customization

Minecraft: 1.21.1 (Fabric)
Default ClickGUI keybind: **Y**
Default command prefix: **;**

## GUI changes
- Lightning Client branded top bar with violet/blue accent
- Dark overlay and centered category panels
- Dark panel cards with violet header accents
- Footer hints for existing mouse controls
- Existing module list, settings widgets, and input handling retained

## Build
Use Java 21, then run `./gradlew build` (Windows: `gradlew.bat build`).
The output JAR should be under `build/libs/`.
